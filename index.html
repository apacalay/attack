Panduan Singkat Attack Planner

1. Unggah Base Screenshot: Seret (drag & drop) gambar base CoC Anda ke kanvas tengah, atau gunakan tombol upload.

2. Sesuaikan Grid Boundaries: Posisikan grid isometric agar sejajar dengan base. Geser base menggunakan drag mouse, dan perbesar/perkecil menggunakan scroll wheel mouse. Jika sudah sejajar, klik tombol "Lock Grid".

3. Buat Strategi: Gunakan menu kiri untuk memilih tool pena/panah taktis atau tambahkan catatan teks, lalu gunakan panel kanan untuk menaruh pasukan, spell, dan hero dengan urutan serang otomatis.

Pintasan Keyboard (Hotkeys):

Undo / Urungkan Ctrl + Z
Redo / Ulangi Ctrl + Y
Hapus Marker Terpilih Delete / Backspace
Batal / Deselect Tool Escape
