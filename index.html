Attack Planner Quick Guide

1. Upload Base Screenshot: Drag & drop your CoC base image onto the center canvas, or use the upload button.

2. Adjust Grid Boundaries: Align the isometric grid with the base. Drag the base using the mouse, and zoom in/out using the scroll wheel. Once aligned, click the "Lock Grid" button.

3. Create Strategy: Use the left menu to select drawing tools or add text notes, then use the right panel to place troops, spells, and heroes with automatic attack ordering.
